# AutoAgent Design

> AutoAgent: Fully-Automated & Zero-Code LLM Agent Framework Design Documentation

## 项目简介

AutoAgent 是一个**完全自动化**且支持**自我进化**的框架，通过纯自然语言即可创建和部署 LLM Agent。

## 核心特性

- 🏆 **GAIA 基准第一** — 开源方法中排名第一，性能媲美 OpenAI Deep Research
- 📚 **原生自管理向量数据库** — Agentic-RAG 表现优于 LangChain
- ✨ **零代码 Agent 创建** — 仅需自然语言即可构建工具、Agent 和工作流
- 🌐 **通用 LLM 支持** — OpenAI、Anthropic、Deepseek、vLLM 等
- 🔀 **灵活交互模式** — 支持 Function Calling 和 ReAct
- 🤖 **动态可扩展** — 轻量级个人 AI 助手
