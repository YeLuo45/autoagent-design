# Starter Projects

Get started quickly with AutoAgent through these ready-to-use starter projects. Each project demonstrates a core use case and provides a foundation for building your own applications.

## [Auto Deep Research](./starter-projects-auto-deep-research)

An automated research assistant that leverages LLM agents to conduct deep, multi-step research tasks. This project demonstrates how to build an autonomous agent capable of planning, executing, and synthesizing information across complex research workflows.

## [From Natural Language to Agent](./starter-projects-nl-to-agent)

A starter template that shows how to convert natural language descriptions into functional agents. This project is ideal for understanding how AutoAgent interprets high-level task descriptions and transforms them into executable agent behaviors.

## [Agentic RAG](./starter-projects-agentic-rag)

An intelligent Retrieval-Augmented Generation system powered by AutoAgent. Unlike traditional RAG approaches with predefined workflows, this implementation enables agents to autonomously decide when and how to retrieve information from a knowledge base, making the retrieval process more adaptive and context-aware.
